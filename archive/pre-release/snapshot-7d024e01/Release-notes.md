# ND LabelDesigner 3.0.8

- Všetky vlastné okná a hlášky majú logo programu a titulok zladený so svetlou alebo tmavou témou.
- Zachované natívne ovládanie okien Windows a systémový vysoký kontrast.
- Obsahuje tiež zmeny 3.0.7: prichytenie rotácie k pravým uhlom s toleranciou ±3° a odstránenie externého otvárania .nlbl.
- README opisuje funkcie, formáty a používanie programu.

Zostavenie a 17 regresných sád prešlo, vrátane 164 kontrol okien a 48 kontrol natívnych atribútov DWM. Fyzická tlač, vysoký kontrast a presun medzi monitormi s rôznym DPI neboli manuálne overované. Systémové dialógy a okná ovládačov zostávajú spravované Windows.

Rozbaľte celý Windows ZIP a spustite ND-LabelDesigner.exe. Konfiguráciu .exe.config ponechajte pri programe. Vyžaduje .NET Framework 4.8/4.8.1. Balík obsahuje zdroje, testy a návod.
