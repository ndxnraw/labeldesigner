# EAN Etikety 1.0 — prvá verzia

Pôvodná prvá verzia programu, z ktorého vznikol ND LabelDesigner. Archívny ZIP je zachovaný bez zmien a obsahuje EAN-Etikety.exe, pôvodný návod a zdrojový kód. Rozbaľte ZIP a postupujte podľa priloženého návodu.

Toto je historické vydanie; neobsahuje funkcie a opravy aktuálneho ND LabelDesigner. Na bežné používanie zvoľte najnovšiu verziu.
