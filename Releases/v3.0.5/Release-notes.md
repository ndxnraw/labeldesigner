# ND LabelDesigner 3.0.5

Stiahnite ZIP, rozbaľte celý obsah a spustite ND-LabelDesigner.exe. Súbor ND-LabelDesigner.exe.config ponechajte vedľa EXE. Vyžaduje Windows a .NET Framework 4.8/4.8.1.

- Horný panel so samostatnými vektorovými ikonami a tooltipmi.
- Nastavenia, Návod a O aplikácii sú dostupné priamo; odstránená ponuka Súbor a duplicita Uložiť ako.
- Zlučovanie rýchlych pohybov myši, obmedzenie prepočtov a zmien titulku počas presúvania.
- Zachované Smart Guides, konečná poloha po pustení myši, Esc, kopírovanie a existujúce exporty.

Balík obsahuje program, konfiguráciu, zdrojový kód, testy, návod a dokumentáciu. Zostavenie a 14 testovacích sád prešlo. Fyzická tlač a správanie na používateľových monitoroch zostávajú na ručné overenie.
